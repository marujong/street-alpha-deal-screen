# Street Alpha Deal Screen MVP

매장 인수 후보를 1차 스크리닝하는 로컬 웹앱입니다.

## 현재 기능
- 매출/비용 입력
- 추정 영업이익 및 단순 회수기간 계산
- 재무 안정성 / 상권·수요 / 대표자 독립성 / 성장 가능성 / 리스크 통제 점수
- 강점, 리스크, 실사 질문 자동 생성
- 텍스트 결과 다운로드

## 설치
Python 3.11+ 권장.

```bash
pip install -r requirements.txt
```

## 실행
```bash
streamlit run app.py
```

브라우저가 자동으로 열리지 않으면 터미널에 표시된 Local URL을 열면 됩니다.

## 설계 원칙
점수는 수식 기반으로 계산하고, 향후 AI는 설명과 추가 질문 생성에만 사용합니다.
같은 입력에 같은 평가가 나와야 평가 기준을 검증할 수 있기 때문입니다.
